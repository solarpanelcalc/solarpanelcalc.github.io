# 태양광발전 허브

무료 태양광발전 계산기 — GitHub Pages용 정적 단일 페이지 사이트.

**라이브 사이트:** https://solarpanelcalc.github.io/

## 사이트 소개

한국어 태양광발전 계산 허브로, 한국 기준(380V 3상 / 220V 단상, 60Hz)과 한국 표준(KS C IEC 61215, KS C 8561, KEC 한국전기설비규정)에 따라 만들었습니다. 순수 HTML5, CSS3, 바닐라 JavaScript만 사용했습니다. 프레임워크, 빌드 단계, 백엔드가 없습니다.

## 계산기 (모두 브라우저 안에서 동작)

1. **발전량 예측** — 설비용량(kWp), 일사 시간, 시스템 효율에서 일·월·연간 발전량을 계산합니다.
2. **패널 소요 수량·면적** — 목표 용량 또는 지붕 면적에서 패널 수량, 소요 면적, 실제 용량을 계산합니다.
3. **인버터 용량** — 직류 용량과 DC/AC 비율에서 인버터 용량과 권장 표준 용량을 계산합니다.
4. **케이블·전압강하** — 직류 전압, 전류, 길이, 케이블 굵기에서 저항, 전압강하, 3% 기준 판정을 계산합니다.
5. **경제성·회수기간** — 설치비, 연간 발전량, 전기요금, 유지비에서 연간 순절감액, 회수기간, 20년 순이익을 계산합니다.

용량별 참고표, 실무 가이드 6편, 자주 묻는 질문, 소개와 면책 조항도 포함되어 있습니다.

## GitHub Pages 배포 방법

1. GitHub 사용자 **motorwindinghub** 아래에 **solar-hub** 이름의 공개 저장소를 만듭니다.
2. 이 폴더의 모든 파일(`index.html`, `README.md`, `.nojekyll`, `favicon.svg`, `guides/`)을 저장소 루트에 업로드합니다.
3. 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch → branch `main`, folder `/ (root)` → Save**를 선택합니다.
4. 몇 분 안에 **https://solarpanelcalc.github.io/** 주소로 사이트가 열립니다.

## 로컬 미리보기


## 면책 조항

모든 계산 결과는 안내용 추정치입니다. 실제 설계와 시공 전에는 패널과 인버터 제조사의 명판 자료, 한국전기설비규정(KEC)과 관련 법령을 확인하십시오. 전기 작업은 반드시 자격을 갖춘 전기기술자에게 맡기십시오.
